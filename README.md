# Puentes · Verificación de credenciales

Sitio estático de una sola página preparado para GitHub Pages.

## Publicación
1. Crear un repositorio público, por ejemplo `puentes-credenciales`.
2. Subir `index.html` a la raíz.
3. En GitHub: Settings → Pages → Deploy from a branch → `main` / root.
4. La URL resultante será similar a:
   `https://USUARIO.github.io/puentes-credenciales/`

Antes de publicar, reemplazar `INCORPORAR_HASH_DEFINITIVO_CONFIRMADO`
por el SHA-256 confirmado del certificado final.
